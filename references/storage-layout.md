# Storage Layout

```
{agent_root}/commons/data/ocas-scout/    → config, JSONL files, briefs/, reports/, dossiers/, caches
{agent_root}/commons/data/ocas-scout/dossiers/{SUBJECT}.md  → intermediate OSINT research dossiers (one per research subject, prior-to-brief storage)
{agent_root}/commons/journals/ocas-scout/ → YYYY-MM-DD/{run_id}.json
```

Read `references/scout_config.md` for default config.json and field descriptions.
